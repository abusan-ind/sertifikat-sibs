📌 Alur Kerja Pembuatan Sertifikat Yayasan

Sistem ini hanya menghasilkan QR Code. Sertifikat fisik dibuat/didesain manual oleh pengurus. QR Code yang diunduh dari sini tinggal ditempelkan ke sertifikat manual tersebut. Ketika QR Code di-scan, sistem otomatis menampilkan data santri untuk memverifikasi keasliannya.

Langkah 1
Isi nomor sertifikat dan nama santri di form bawah ini.
Langkah 2
Unduh QR Code murni (atau unduh format stiker siap cetak).
Langkah 3
Tempelkan QR Code pada sertifikat manual (Canva / Corel / kertas blangko).
Langkah 4
Saat di-scan pakai HP santri, web memverifikasi keasliannya secara resmi.
